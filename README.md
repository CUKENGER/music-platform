# Project setup

## Requirements

- Node.js (recommended LTS)
- pnpm
- Docker (for dev-config)

## Installation

### 1. Install pnpm globally

```bash
npm -g install pnpm
```

---

### 2. Install client dependencies

```bash
cd client
```

```bash
pnpm install
```

---

### 3. Install server dependencies

```bash
cd server
```

```bash
pnpm install
```

---

### 4. Start dev environment

```bash
cd dev-config
```

```bash
make up
```
